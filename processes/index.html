    The Process Reference lists all 49 named processes individually in canonical Atlas reference order. Use it for process purpose, mechanics, position, and relationships; the order is a reference structure, not a mandatory one-time execution chronology.

    The same process system can also be read by process group or lifecycle context and by subject-area flow. Recurring role, authority, delivery-approach, issue, compliance, and benefits terms use the AI Semantic Reference; each process page retains context-specific authority.

    Delivery-approach legend

    Badges describe applicability, not exclusive ownership. An Adaptive badge may represent an iterative equivalent or treatment rather than identical performance of the formally named process.
